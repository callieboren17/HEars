# Hearing-Related Empowerment Study

This repository contains the data and R analysis code accompanying the manuscript *Hearing-Related Empowerment as a Complement to Traditional Measures of Hearing Difficulties*.

The study examines relationships between hearing-related empowerment, hearing aid use, audiometric hearing loss, auditory communication difficulties, psychosocial factors, and hearing aid satisfaction in older adults.

## Repository Contents

- `HEars_public.csv` — Public-use dataset containing selected variables necessary to reproduce the analyses. This dataset does not include the full original research dataset.
- `HEars_public_analysis.R` — R script used to conduct the statistical analyses and generate figures.

## Reproducing the Analyses

Download both files into the same directory, open the R script in RStudio, install any required packages, and run the script.
